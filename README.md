# Проект "Виджетом банковских операций"

---
## Описание:
 
Проект, который на бэкенде будет готовить данные для отображения в новом виджете. Этот виджет показывает несколько последних успешных банковских операций клиента.

Согласно заданий:
- 10.1 реализованы функции,
- 10.2 прописаны тесты,
- 11.1 генераторы,
- 11.2 декораторы.
---
## Установка:  
1. Клонируйте репозиторий: 
``` 
git clone https://github.com/Alexandra111111111/mybank_widget.git 
```

``` 
pip install -r requirements.txt
```

##  Использованные модули:
### 1. Модуль masks.py
Модуль предоставляет функции для работы с банковскими картами 
- 'get_mask_card_number' : принимает на вход номер карты в виде числа и возвращает маску номера по правилу 
XXXX XX** **** XXXX
- 'get_mask_account' - принимает на вход номер счета в виде числа и возвращает маску номера по правилу 
**XXXX

### 2. Модуль widjet.py
Этот модуль  содержит функции для работы с новыми возможностями приложения.
- 'get_date' , которая принимает на вход строку с датой в формате"2024-03-11T02:26:18.671407" и возвращает строку с датой в формате"ДД.ММ.ГГГГ" (11.03.2024").
 - 'mask_account_card' , которая умеет обрабатывать информацию как о картах, так и о счетах.


### 3. Модуль processing.py
Модуль предоставляет функции для работы с банковскими операциями:

- `filter_by_state` Функция принимает список словарей и значение для ключа и возвращает новый
    список содержащий только те словари у которых ключ содержит переданное значение.
- `sort_by_date`Функция принимает список и сортирует его по убыванию.


### 4. Модуль generators:
- `filter_by_currency` Функция фильтрации транзакций по заданному типу валюты.
- `transaction_descriptions` Генератор, позволяющий получать последовательные описания транзакций.
- `card_number_generator` Генерация номеров банковских карт в необходимом диапазоне.

### 5. Модуль decorators:
Новый функционал: Декорация функций с регистрацией выполнения.
- `log`
Этот декоратор помогает вести журнал действий ваших функций. Он сохраняет название функции, её входные данные, результат успешного выполнения или возникающую ошибку вместе с параметрами функции.

Особенности:
- Поддерживает ведение журнала как в консоли, так и в отдельном файле.
- Возможность записи результатов и подробностей выполняемых операций.
- Полностью интегрирован с системой автоматического тестирования.

### 6. Модульное тестирование:

Тесты подготовлены отдельными файлами под каждый модуль функционала:
1. `test_masks.py`
- `test_len_mask_card_number` проверяет длину номера карты.
- `test_len_get_mask_account` проверяет длину номера счета.
- `test_get_mask_card_number` вызов исключения `ValueError` и проверка функции (для карт) на выполнение.
- `test_get_mask_account` вызов исключения `ValueError` и проверка функции (для счетов) на выполнение.

2. `test_processing.py`
- `test_transformat_int_str` Тест проверяет функцию, преобразующую числовые идентификаторы (int) в строковые (str).
- `test_filter_by_state` Тест проверяет корректность работы функции, которая фильтрует список словарей по состоянию (state).
- `test_sort_by_date_descending` Тест сортировки по дате в порядке убывания.
- `test_sort_by_date_ascending` Тест сортировки по дате в порядке возрастания.
- `test_sort_by_same_dates` Тест сортировки при одинаковых датах.
- `test_incorrect_date_format` Тест на некорректные форматы дат.

5. `test_widget.py`
- `test_mask_account_card` Тест проверяет корректность работы функции, которая маскирует банковские реквизиты (номер карты или счёта) в зависимости от типа входных данных.
- `test_get_date` Тест проверяет корректность преобразования даты из строки формата ISO8601 (YYYY-MM-DDTHH:MM:SS.mmmmmm) в русский формат (DD.MM.YYYY).
- `test_get_date_error_handling` Тест проверяет, что функция корректно обрабатывает некорректные или неверные входные данные и выводит соответствующие исключения (ValueError).

6. `test_generators.py`
- `test_filter_by_currency` Проверяет фильтрацию транзакций по валюте.
- `test_transaction_descriptions` Проверяет корректность вывода описаний транзакций.
- `test_card_number_generator` Проверяет работу генератора номеров карт.

7. `test_decorators.py`
- `test_successful_execution_console_output` Тест проверяет корректную регистрацию успеха ("ok") при успешном выполнении функции. Создается временная функция example_function, вызывается и проверяется наличие сообщения `example_function ok` в логах с помощью фикстуры caplog.
- `test_error_handling_console_output` Тест проверяет обработку ошибок декоратором. Функция `failing_function` бросает исключение (ValueError), и проверяется регистрация ошибки с деталями через `caplog`.
- `test_successful_execution_to_file` Тест проверяет сохранение логов в файл при успешном выполнении функции `another_example_function`. Содержимое файла проверяется на наличие сообщения о успехе.
- `test_error_handling_in_file` Тест имитирует ошибку функцией `another_failing_function` и проверяет регистрацию ошибки в файле. Созданный лог-файл открывается и проверяется на наличие сообщения об ошибке.
