# Проект "ДЗ"

## Описание:
 
Проект, который на бэкенде будет готовить данные для отображения в новом виджете. Этот виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:  
1. Клонируйте репозиторий: 
``` 
git clone https://github.com/Alexandra111111111/mybank_widget.git 
``` 
2. Установите зависимости: 
``` 
pip install -r requirements.txt 
```
